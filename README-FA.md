# فنلاندی از صفر — نسخه V6

اپ رایگان یادگیری فنلاندی با ۵۰ مرحله، گرامر، بازی، آزمون، دوربین واژگان و تلفظ.

## امکانات جدید
- ورود با گوگل (بدون ایمیل تأیید) و ورود/ثبت‌نام با ایمیل و رمز عبور از طریق Supabase Auth؛ بازی‌ها و درس‌ها بدون حساب باز هستند.
- پشتیبانی تیکتی داخل اپ؛ کاربر می‌تواند تیکت ایجاد کند، وضعیت و پاسخ‌ها را ببیند.
- پنل مدیر برای پاسخ و بستن تیکت‌ها با مجوز امن دیتابیس (RLS).
- هیچ ایمیل پشتیبانی در فایل‌های منتشرشده ذخیره یا نمایش داده نمی‌شود.

## راه‌اندازی
پروژه Supabase و اجرای SQL ضروری است. تنظیمات عمومی پروژه در `auth-config.js` قرار می‌گیرند. **هرگز secret یا service_role key را در این فایل قرار ندهید.**
راهنمای خصوصی راه‌اندازی و فایل SQL جدا از ZIP انتشار ارائه شده‌اند.

## محدودیت‌ها
- بدون تنظیم Supabase، ثبت‌نام و تیکت فعال نمی‌شوند؛ سایر بخش‌های اپ قابل استفاده‌اند.
- تیکت‌ها داخل اپ و داشبورد Supabase قابل مشاهده‌اند؛ ارسال خودکار پیام به صندوق ایمیل نیاز به سرویس ایمیل جداگانه دارد و در این نسخه فعال نیست.
- پیشرفت یادگیری در مرورگر ذخیره می‌شود، نه روی حساب ابری.
- کیفیت صدای فنلاندی و دوربین به دستگاه و مرورگر بستگی دارد.

**مهم:** سرویس ایمیل پیش‌فرض Supabase برای ثبت‌نام عمومی کافی نیست و به آدرس‌های غیرمجاز ایمیل نمی‌فرستد. برای ثبت‌نام ایمیلی عمومی باید SMTP جداگانه فعال شود؛ برای شروع، ورود با گوگل را تنظیم کنید.
