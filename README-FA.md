# فنلاندی از صفر — نسخه ۷ (پروفایل + صدای بازی‌ها)

## تغییرات
- پروفایل با نام، عکس و ایمیل حساب Google/Supabase؛ در حالت مهمان هم پیشرفت نشان داده می‌شود.
- نمایش ستاره‌ها، روزهای متوالی، درس‌ها و بخش‌های تکمیل‌شده.
- میانبر پروفایل در بالای اپ و منوی «بیشتر».
- دکمه شنیدن تلفظ در بازی کلمه و معنی، پاسخ درست و بازی حافظه.
- صدای کوتاه موفقیت/اشتباه بازی با امکان خاموش‌کردن در تنظیمات.
- بهبود راه‌اندازی صدای فنلاندی در iPhone Safari / PWA.
- بازگشت صحیح از بازی‌های آزاد.

## انتشار در GitHub Pages
فایل‌های داخل ZIP را در ریشه مخزن GitHub آپلود و جایگزین کنید (فقط ZIP را به مخزن نفرستید). چند دقیقه بعد اپ را کامل ببندید و دوباره باز کنید تا کش نسخه ۷ جایگزین شود.

## نکات مهم
- این ZIP شامل URL و **کلید عمومی publishable** پروژه Supabase قبلی است؛ کلید محرمانه ندارد.
- پیشرفت فعلاً فقط در همان مرورگر/دستگاه نگهداری می‌شود، نه در حساب ابری.
- صدای تلفظ وابسته به موتور گفتار و صدای نصب‌شده روی دستگاه است. صداهای موفقیت/اشتباه در iOS به اجازه صوتی مرورگر و میزان صدای گوشی وابسته‌اند.
- رفع خطای `permission denied for table support_tickets` نیازمند بررسی مجوزهای دیتابیس Supabase است؛ تغییرات این نسخه به‌تنهایی آن را برطرف نمی‌کند. RLS را خاموش نکنید.
