# Finnish az Sefr — نسخه ۱۱ (آزمایشی برای بررسی نهایی)

این فایل‌ها پروژه کامل PWA برای GitHub Pages هستند؛ APK یا IPA نیستند.

## تغییرات
- حذف نوشته‌های توضیحی غیرضروری در گرامر و درس، حذف ورود گوگل، حذف توضیح ذخیره محلی از صفحه پروفایل، حذف دانلود فایل پشتیبان از تنظیمات.
- ورود فقط با ایمیل/رمز عبور Supabase؛ پس از ثبت‌نام بدون نشست فعال، پیام پایدار «لطفاً ایمیلت را تأیید کن» و ارسال مجدد تأیید نمایش داده می‌شود. پس از ورود موفق، فرم ورود پنهان و پروفایل نمایش داده می‌شود.
- عکس پروفایل انتخابی از گوشی یا یکی از هشت آیکن؛ فقط به‌صورت محلی روی همان گوشی ذخیره می‌شود، نه در حساب ابری.
- پیش‌نمایش مهمان: گرامر ۱، اولین بازی، سطح A1 آزمون و اولین دسته‌بندی؛ بخش‌های دیگر با ورود و تأیید ایمیل باز می‌شوند. **در مسیر ۵۰ مرحله‌ای، فقط مرحله اول برای مهمان باز است و بقیه پس از ورود و تکمیل مرحله قبلی باز می‌شوند؛ مسیر همچنان آموزشی و مرحله‌به‌مرحله است**: هر مرحله با تکمیل چهار بخش قبلی باز می‌شود.
- آزمون‌ها و بازی‌ها: دکمه «آزمون/بازی جدید» با انتخاب جدید و «تکرار همین سؤال‌ها» با همان پرسش‌ها. پرسش‌های جدید از بانک موجود انتخاب می‌شوند و ممکن است گاهی تصادفاً تکرار شوند.
- تلفظ آهسته‌تر در موتور گفتار دستگاه، اما کیفیت و میزان اثر سرعت به iOS/Android و صدای نصب‌شده وابسته است؛ صدای ثابت حرفه‌ای هنوز پیاده‌سازی نشده.
- یادآوری اختیاری در زمان باز بودن/بازگشت به اپ، با اجازه اعلان در مرورگرهای پشتیبانی‌شده. **این نسخه اعلان پس‌زمینه زمانی که اپ کاملاً بسته است ارسال نمی‌کند**؛ برای این قابلیت سرویس Push، مجوز و تنظیمات سرور لازم است. آیفون معمولاً برای اعلان PWA نیاز به نصب روی Home Screen دارد.
- راهنمای نصب آیفون و اندروید؛ لینک‌های اینستاگرام و یوتیوب؛ لوگوی نوشته‌دار قبلی.

## تنظیمات ضروری پیش از معرفی عمومی
1. در Supabase بخش Authentication → Providers → Email، ارسال ایمیل و **Confirm email** را فعال نگه دارید. در URL Configuration آدرس سایت GitHub Pages را به Redirect URLs اضافه کنید: `https://finnishazsefr.github.io/finnish-az-sefr/**` . اگر سرویس ایمیل Supabase محدودیت دارد، SMTP اختصاصی برای تعداد کاربر واقعی نیاز می‌شود.
2. در یک مرورگر ناشناس ثبت‌نام آزمایشی کنید: پیام تأیید، دریافت ایمیل، کلیک لینک، ورود و نمایش پروفایل را چک کنید. فقط دیدن فرم کافی نیست.
3. تلفظ و یادآوری را در آیفون Safari و اندروید Chrome تست کنید. اعلان در زمان بسته بودن کامل اپ **پشتیبانی نمی‌شود**.
4. `features.js` پشتیبانی تیکتی را تا حل خطای دسترسی پایگاه داده غیرفعال نگه می‌دارد.
5. پیشرفت، اشتباهات و عکس پروفایل بین دستگاه‌ها همگام‌سازی نمی‌شوند؛ در حافظه محلی دستگاه هستند. با پاک شدن داده مرورگر ممکن است از دست بروند.
6. اگر Supabase احراز هویت کار نکند، بخش‌های قفل‌شده باز نخواهند شد؛ تا زمان تست موفق، انتشار عمومی توصیه نمی‌شود.
