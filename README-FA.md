# فنلاندی از صفر — نسخه ۴ (GitHub Pages)

این پوشه یک اپ وب قابل نصب (PWA) با رابط فارسی است. تمام فایل‌ها باید در ریشه مخزن GitHub Pages قرار بگیرند.

## قابلیت‌های این نسخه
- تم تیره آبی با تصویر راهنمای کارتونی، کارت‌های درشت و انیمیشن‌های سبک هنگام تغییر صفحه و انتخاب‌ها.
- مسیر ۵۰ مرحله‌ای از A0 تا موضوعات مقدماتی B1؛ مرحله اول کل ۲۹ حرف و مرحله دوم اعداد ۰ تا ۱۰ است.
- چهار بخش برای هر مرحله: آموزش/فلش‌کارت، گوش دادن، بازی تطبیق، آزمون و نوشتن. بخش بعدی بعد از تکمیل بخش قبلی باز می‌شود. قبولی بخش‌های ارزیابی حداقل ۴ پاسخ درست از ۵ پاسخ است.
- سه بازی تمرینی مستقل: انتخاب معنی، تشخیص شنیداری، پیدا کردن جفت کارت‌های حافظه.
- دسته‌بندی موضوعی واژگان با «همه»، «بلدم»، «بلد نیستم»، ذخیره لغات و دفترچه واژگان.
- ۱۳ مبحث کوتاه گرامری با توضیح فارسی و مثال؛ تدریجی و متناسب با سطح. این بخش **جایگزین کتاب یا دوره جامع A1 تا B1 نیست**.
- دوربین/گالری برای تشخیص متن فنلاندی (OCR) و تطبیق با فرهنگ محدود داخل اپ.
- تلفظ با سرعت عادی/آهسته و انتخاب ترجیح صدای زن/مرد **در صورت وجود صدای فنلاندی مناسب روی دستگاه**. فایل صوتی ضبط‌شده یا صدای تضمین‌شده زن/مرد وجود ندارد.
- ذخیره پیشرفت روی همان مرورگر (localStorage)، بدون حساب کاربری یا تبلیغات.

## جایگزین کردن نسخه قدیمی در GitHub (روی آیفون)
1. ZIP را در Files آیفون باز کن تا از حالت فشرده خارج شود.
2. وارد مخزن `FinnishAzSefr/finnish-az-sefr` شو.
3. گزینه `Add file` → `Upload files` را انتخاب کن.
4. **محتویات داخل پوشه استخراج‌شده** را انتخاب کن (نه خود ZIP و نه یک پوشه اضافه). این فایل‌ها باید کنار `index.html` در ریشه مخزن باشند.
5. فایل‌های هم‌نام باید با نسخه جدید جایگزین شوند؛ تغییرات را `Commit changes` کن. GitHub Pages از شاخه `main` و مسیر `/(root)` منتشر می‌شود.
6. بعد از انتشار، سایت را در Safari باز و یک بار Refresh کن. اگر نسخه قبلی دیده شد، صفحه را دوباره بارگذاری کن یا میانبر قدیمی را ببند و باز کن.

**هشدار:** GitHub در برخی نماهای موبایل اجازه جایگزینی فایل هم‌نام از مسیر Upload را نمی‌دهد یا پیام conflict می‌دهد. در این حالت باید فایل‌ها را با ابزار Git مناسب/نمای دسکتاپ یا ویرایش تک‌تک فایل‌ها به‌روز کنی؛ نباید فایل‌ها را در پوشه تو در تو آپلود کنی. فایل ZIP به تنهایی سایت را به‌روز نمی‌کند.

## محدودیت‌ها
- OCR برای بار اول موتور و داده‌های زبانی را از CDN دانلود می‌کند؛ اتصال اینترنت و کیفیت تصویر مهم است. عکس به سرور متعلق به این اپ ارسال نمی‌شود، ولی کد و مدل OCR از سرویس بیرونی بارگیری می‌شود.
- صدا از قابلیت Speech Synthesis مرورگر استفاده می‌کند و کیفیت/جنسیت صدا روی iOS وابسته به صداهای نصب‌شده است.
- بازی‌ها، درس‌ها و گرامر محتوای مقدماتی هستند و برای تکمیل آموزشی و بازبینی تخصصی نیاز به کار بیشتر دارند.
- پاک کردن داده‌های Safari ممکن است پیشرفت را از بین ببرد. از بخش تنظیمات فایل پشتیبان JSON بگیر.
- فایل `home-guide.webp` برش یک طرح کارتونی ساخته‌شده برای همین پروژه است.

## ساختار فایل‌ها
