# Finnish az Sefr — نسخه ۱۰ برای GitHub Pages

این ZIP شامل **فایل‌های کامل سایت** است، نه APK یا IPA. همه فایل‌های داخل ZIP را **مستقیم در ریشه مخزن** `FinnishAzSefr/finnish-az-sefr` آپلود/جایگزین کنید (نه خود فایل ZIP و نه پوشهٔ اضافی).

## امکانات
- حفظ درس‌های ۵۰ مرحله‌ای، واژگان، گرامر، پنج بازی قبلی، تلفظ و پروفایل
- بازی ششم «خودت رو امتحان کن!»: ۱۰ سؤال تصادفی چهارگزینه‌ای، سطوح A1 / A2 / B1 مقدماتی، سؤال از فارسی به فنلاندی و برعکس، نمایش ترجمه فارسی و انگلیسی، دکمه تلفظ و مرور اشتباهات
- امتیاز و اشتباهات در حافظهٔ محلی دستگاه؛ بدون نیاز به ورود
- لوگوی پرچم فنلاند با نوشتهٔ Finnish az Sefr
- نسخه جدید service worker برای دریافت به‌روزرسانی و صفحه حریم خصوصی `privacy.html`
- لینک‌های رسمی اینستاگرام و یوتیوب در صفحه «بیشتر»

## آزمون انجام‌شده
- بررسی نحوی فایل‌های JavaScript و اجرای شبیه‌سازی منطق آزمون در سه سطح: هر سطح ۱۰ سؤال با چهار گزینه، نمایش بازخورد و نتیجه، ثبت اشتباهات و امتیاز.
- این آزمون جایگزین تست عملی روی Safari و Chrome و بررسی ورود Google نیست.

## نکات پیش از معرفی عمومی
1. آدرس **پیش‌بینی‌شده بر اساس آدرس قبلی مخزن** پس از انتشار در GitHub Pages: https://finnishazsefr.github.io/finnish-az-sefr/ (تا پیش از انتشار، لینک نسخه قدیمی را نشان می‌دهد).
2. پس از آپلود، سایت را روی Safari آیفون و Chrome اندروید باز کنید. تست کنید: صفحه خانه، شروع درس، بازی چهارگزینه‌ای A1/A2/B1، مرور اشتباهات، صدا، برگشت، ذخیره پیشرفت و نصب روی صفحه اصلی.
3. ورود گوگل فقط در صورت صحت تنظیمات Supabase/Google OAuth کار می‌کند؛ از اینجا تست واقعی آن ممکن نیست.
4. **پشتیبانی تیکتی عمداً در نسخه عمومی مخفی است** چون قبلاً خطای `permission denied for table support_tickets` داشت. برای فعال کردن آن ابتدا باید دسترسی‌های پایگاه داده و API در Supabase اصلاح و تست شوند؛ سپس `features.js` را تغییر دهید. RLS را خاموش نکنید.
5. تلفظ از موتور گفتار گوشی استفاده می‌کند؛ سرعت آرام است اما کیفیت و صدای دقیق روی دستگاه‌های مختلف متفاوت است. اگر صدای Finnish روی دستگاه موجود نباشد، کیفیت تلفظ تضمین نمی‌شود.
6. فایل `auth-config.js` فقط کلید عمومی Supabase را دارد؛ هرگز service_role/secret key را در GitHub قرار ندهید.
7. اطلاعات پیشرفت فعلاً روی همان گوشی ذخیره می‌شود، نه حساب آنلاین. داده‌ها را می‌توان از تنظیمات پشتیبان گرفت.

## انتشار با آیفون
**فایل ZIP را مستقیم در GitHub آپلود نکنید.** ابتدا آن را در برنامه Files آیفون باز و از حالت فشرده خارج کنید. سپس فایل‌های داخلی (index.html, app.js, style.css و بقیه) را در ریشه مخزن بارگذاری کنید. اگر GitHub روی گوشی اجازه انتخاب چند فایل نداد، از Safari گزینه Request Desktop Website را بزنید یا فایل‌ها را جداگانه انتخاب کنید.
- GitHub > مخزن `finnish-az-sefr` > **Add file > Upload files** (در صورت نیاز از Safari گزینه Request Desktop Website).
- فایل‌های ZIP را در Files آیفون **Uncompress** کنید و فایل‌های داخل پوشه را انتخاب کنید.
- پایین صفحه **Commit changes** را بزنید و چند دقیقه بعد سایت را باز کنید.
- اگر هنوز نسخه قدیمی دیده می‌شود: صفحه را Refresh کنید؛ برای آیکون قدیمی ممکن است لازم باشد میانبر نصب‌شده را حذف و دوباره Add to Home Screen کنید.
