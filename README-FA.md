# فنلاندی از صفر — نسخه آزمایشی ۲.۰

این پوشه یک وب‌اپ قابل نصب (PWA) است. فایل اصلی `index.html` و همه فایل‌های لازم در ریشه پوشه هستند.

## قابلیت‌های واقعی این نسخه
- رابط فارسی راست‌به‌چپ، طراحی تیره زغالی/آبی، متن‌های درشت، دکمه‌های برجسته و واکنش هنگام لمس
- ۸ درس مقدماتی مرتب‌شده از A0 تا موضوعات اولیه A1؛ هر درس ۴ مرحله اجباری دارد: آموزش واژه‌ها و تلفظ، فلش‌کارت با دکمه‌های «بلدم» و «بلد نیستم»، کوییز ۵ سؤالی و تمرین نوشتن ۵ سؤالی
- باز شدن مرحله بعد به ترتیب. برای قبولی در کوییز و نوشتن باید حداقل ۴ سؤال از ۵ سؤال درست باشد.
- باز شدن درس بعد فقط پس از تکمیل هر ۴ مرحله؛ امتیاز ستاره‌ای و ذخیره پیشرفت روی همان دستگاه
- چالش روزانه ۵ واژه، دفترچه لغات، افزودن دستی واژه، مرور اشتباهات و خروجی JSON
- دوربین/گالری و تشخیص متن OCR روی دستگاه با Tesseract.js؛ معنی فارسی و انگلیسی فقط برای لغات موجود در بانک واژگان
- قابل نصب روی صفحه اصلی گوشی بعد از انتشار با HTTPS

## محدودیت‌های صادقانه قبل از تبلیغ عمومی
- این یک **نسخه آزمایشی** است و هنوز به یک آدرس عمومی منتشر نشده. بدون آپلود فایل‌ها هیچ لینک عمومی برای اشتراک‌گذاری وجود ندارد.
- مرحله آموزش در نسخه ۲، **درس متنی + دکمه تلفظ صوتی دستگاه** است، نه ویدیوی ضبط‌شده معلم.
- در بخش بازی و فلش‌کارت از ایموجی استفاده شده؛ تصاویر واقعی/انیمیشن سه‌بعدی کامل هنوز پیاده‌سازی نشده‌اند.
- واژه‌نامه اولیه محدود است. این برنامه مترجم کامل یا ابزار قابل اتکا برای تفسیر اطلاعات پزشکی، آلرژن یا قرارداد نیست.
- OCR در اولین استفاده باید موتور و داده زبان را از اینترنت بارگیری کند و ممکن است روی بعضی دستگاه‌ها خطا بدهد. تشخیص متن به کیفیت عکس بستگی دارد.
- تلفظ به پشتیبانی دستگاه از گفتار فنلاندی بستگی دارد. بدون صدای فنلاندی ممکن است تلفظ نامناسب یا ناموجود باشد.
- حساب کاربری، همگام‌سازی بین دستگاه‌ها و سرور ذخیره عکس وجود ندارد. پاک شدن داده‌های مرورگر ممکن است پیشرفت را پاک کند.
- ظاهر، دوربین و نصب PWA باید روی آیفون/اندروید واقعی و بعد از انتشار با HTTPS آزمایش شوند.

## انتشار رایگان برای لینک عمومی
1. از فایل ZIP این پروژه استفاده کنید و آن را در برنامه Files ذخیره کنید.
2. وارد https://app.netlify.com/drop شوید و با حساب رایگان وارد شوید.
3. اگر Netlify فایل ZIP را مستقیماً نپذیرفت، آن را در Files باز/استخراج کنید و پوشه شامل `index.html` را بارگذاری کنید. بسته به نسخه مرورگر موبایل، ممکن است آپلود پوشه دشوار باشد؛ در این صورت انتشار از لپ‌تاپ راحت‌تر است.
4. بعد از انتشار، آدرس HTTPS واقعی از Netlify دریافت می‌کنید؛ آن را در Safari باز و تمام مراحل را تست کنید.
5. آیفون: Safari → Share → Add to Home Screen → Add. اندروید: Chrome → منوی سه‌نقطه → Install app یا Add to Home screen.
6. قبل از تبلیغ در اینستاگرام، اسکن، ذخیره لغات، کوییز و پیشرفت را با چند گوشی واقعی بررسی کنید. سپس لینک واقعی را در بیو قرار دهید.

## حریم خصوصی
اطلاعات واژه‌ها و پیشرفت با localStorage روی دستگاه نگهداری می‌شوند. تصاویر اسکن‌شده به سرور اپلیکیشن فرستاده نمی‌شوند؛ کتابخانه و مدل OCR از CDN دانلود می‌شوند. هنگام استفاده از فایل‌های شخصی یا حساس احتیاط کنید.

## ساختار
`index.html`, `style.css`, `app.js`, `data.js`, `curriculum.js`, `manifest.webmanifest`, `sw.js`, `icons/`.

## نگهداری و ویرایش
- برای افزودن لغات عمومی، فایل `data.js` را ویرایش کنید.
- برای افزودن درس‌های ترتیبی، فایل `curriculum.js` را ویرایش کنید.
- برای تغییر رنگ و فونت، فایل `style.css` را ویرایش کنید.
- بعد از تغییر فایل‌ها، نسخه نام cache در `sw.js` را افزایش دهید تا نسخه قبلی روی گوشی باقی نماند.
