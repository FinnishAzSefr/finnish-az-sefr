# Finnish az Sefr — V12 | لوگوی ثابت + Web Push واقعی

## چه چیزی در این نسخه تغییر کرد؟

- **لوگو تغییر نکرده**: `icon-192.png` و `icon-512.png` دقیقاً همان فایل‌های تأییدشده نسخه ۸ هستند (پرچم فنلاند با نوشته Finnish az Sefr).
- نسخه ۱۱ با بازی‌ها، ورود ایمیلی، پروفایل و درس‌ها حفظ شده است.
- یادآوری قدیمی که فقط هنگام باز شدن اپ کار می‌کرد، با **سیستم Web Push مبتنی بر OneSignal** جایگزین شده است. کاربر باید خودش روی «فعال‌کردن» بزند و اجازه اعلان بدهد؛ دکمه خاموش‌کردن نیز وجود دارد.
- سرویس‌ورکر جداگانه `OneSignalSDKWorker.js` برای Push اضافه شده تا `sw.js` آفلاین اپ دست‌نخورده بماند.
- زمان‌بندی خودکار **۲۰:۰۰ به وقت فنلاند** با GitHub Actions آماده است (هر ساعت بررسی می‌کند، اما فقط ساعت ۲۰ ارسال می‌کند؛ اجرا ممکن است با تأخیر همراه باشد).
- بخش حریم خصوصی با توضیح پردازش اطلاعات فنی اعلان به‌روز شده است.

**مهم: آپلود فایل‌ها به‌تنهایی Push را فعال نمی‌کند.** بدون OneSignal App ID، کلید محرمانه OneSignal در GitHub Secrets و فعال‌سازی GitHub Actions، هیچ اعلان واقعی ارسال نمی‌شود. این محدودیت عمدی است تا اشتراک جعلی/گمراه‌کننده نمایش داده نشود.

## مرحله ۱ — OneSignal

1. در https://onesignal.com یک حساب ایجاد کن و یک اپ با نام `Finnish az Sefr` بساز.
2. **Web Push** را به‌عنوان پلتفرم انتخاب کن. آدرس سایت GitHub Pages: `https://finnishazsefr.github.io` و آدرس اپ: `https://finnishazsefr.github.io/finnish-az-sefr/` است. اگر داشبورد آدرس کامل را خواست، آدرس کامل را وارد کن. مطمئن شو دامنه و مسیر با تنظیمات سایت سازگارند.
3. در **Settings → Keys & IDs**، `App ID` را کپی کن و فقط داخل `push-config.js` در مقدار `appId` قرار بده. **App ID عمومی است**.
4. در تنظیمات Service Worker (اگر پرسید)، فایل worker را `https://finnishazsefr.github.io/finnish-az-sefr/OneSignalSDKWorker.js` و scope را `/finnish-az-sefr/push/` تنظیم کن. اگر OneSignal به مسیر یا scope متفاوت نیاز داشت، همان مقادیر را هم در `push.js` تغییر بده. Worker باید با کد 200 قابل دسترسی باشد.
5. `App API Key` محرمانه است؛ **آن را داخل هیچ فایل سایت، چت عمومی یا مخزن GitHub قرار نده**.

## مرحله ۲ — انتشار فایل‌ها در GitHub

فایل‌های ریشه را در مخزن `FinnishAzSefr/finnish-az-sefr` جایگزین کن. ZIP را مستقیماً آپلود نکن. فایل‌های جدید ریشه: `push-config.js`, `push.js`, `OneSignalSDKWorker.js`.

برای زمان‌بندی، دو فایل توی پوشه‌های تو در تو هم باید به همان مسیرها اضافه شوند:
- `.github/workflows/daily-practice-push.yml`
- `scripts/send-reminder.mjs`

اگر از آیفون پوشه‌ها را نمی‌توانی آپلود کنی، در GitHub از **Add file → Create new file** استفاده کن و دقیقاً همین مسیرها را به‌عنوان نام فایل بنویس؛ محتوای فایل‌های داخل ZIP را در آن‌ها کپی کن. فایل‌های داخل پوشه مخفی `.github` را حذف نکن.

## مرحله ۳ — GitHub Secrets (الزامی برای ارسال خودکار)

در مخزن GitHub برو به **Settings → Secrets and variables → Actions → New repository secret** و این دو مورد را اضافه کن:
- `ONESIGNAL_APP_ID` = همان App ID عمومی
- `ONESIGNAL_API_KEY` = **App API Key محرمانه** از OneSignal

GitHub Actions باید برای مخزن فعال باشد. Workflow به‌صورت زمان‌بندی‌شده از OneSignal API برای ارسال به بخش **Subscribed Users** استفاده می‌کند. اگر OneSignal حساب شما این Segment را ندارد، در داشبورد یک Segment با همین نام بساز یا نام آن را در `scripts/send-reminder.mjs` عوض کن.

**آزمون ایمن:** ابتدا در OneSignal برای گوشی خودت `Test Users` segment بساز و گوشی را به آن اضافه کن. بعد در GitHub → Actions → Daily Finnish practice push → Run workflow را اجرا کن. اجرای دستی فقط برای `Test Users` می‌فرستد، نه همه کاربران. ارسال زمان‌بندی‌شده برای `Subscribed Users` است.

## مرحله ۴ — تست روی گوشی

- **اندروید:** سایت را در Chrome باز کن؛ Settings → یادآوری تمرین → فعال‌کردن → Allow.
- **آیفون iOS 16.4+:** سایت را در Safari باز کن، Share → Add to Home Screen. **از آیکون روی Home Screen وارد اپ شو** و در تنظیمات، اعلان را فعال کن. اعلان از تب عادی Safari روی آیفون فعال نمی‌شود.
- در OneSignal → Audience → Subscriptions بررسی کن گوشی به‌عنوان Subscribed ثبت شده باشد.
- با `Run workflow` یک اعلان تست به Test Users بفرست و اپ را کامل ببند؛ باید اعلان روی گوشی ظاهر شود (مشروط به تنظیمات سیستم‌عامل و اتصال شبکه).
- دکمه خاموش‌کردن را تست کن؛ بعد از لغو عضویت نباید Push جدید برسد.

## محدودیت‌ها و نکات انتشار عمومی

- فایل‌ها در این بسته **پیکربندی اولیه Push** را دارند؛ اتصال به حساب OneSignal شما و تست تحویل اعلان در این محیط ممکن نیست. بدون App ID، دکمه اعلان در اپ غیرفعال خواهد بود.
- GitHub Actions اجرای زمان‌بندی‌شده را دقیقاً سر ساعت تضمین نمی‌کند. برای یادآوری آموزشی مناسب است، نه اعلان حیاتی.
- Push ممکن است تحت محدودیت Focus، Battery Saver، قطع اینترنت، رد مجوز یا تنظیمات دستگاه قرار بگیرد.
- سرویس OneSignal و GitHub Actions ممکن است محدودیت‌های پلن رایگان و مصرف داشته باشند؛ قبل از رشد کاربران، شرایط فعلی را بررسی کن.
- احراز هویت ایمیلی Supabase، دریافت ایمیل تأیید و صدا هنوز باید روی گوشی واقعی تست شوند. پیشرفت‌ها همچنان فقط در حافظه همان دستگاه‌اند.
- سرویس پشتیبانی تیکتی تا رفع مجوزهای دیتابیس غیرفعال است.

## فایل‌های اصلی

- `push-config.js`: App ID عمومی OneSignal (فعلاً خالی)
- `push.js`: اشتراک/لغو اشتراک با رضایت کاربر و تشخیص نصب روی آیفون
- `OneSignalSDKWorker.js`: دریافت Push در پس‌زمینه
- `.github/workflows/daily-practice-push.yml`: اجرای زمان‌بندی‌شده در GitHub
- `scripts/send-reminder.mjs`: ارسال از سمت سرور با کلید خصوصی موجود در GitHub Secrets


## نسخه ۱۴: پیشنهاد اعلان بعد از ورود و لغت روز
- بعد از **ورود موفق با ایمیل و رمز** (نه صرفاً بازکردن اپ)، در پروفایل پیام خوشامد و پیشنهاد فعال‌سازی یادآوری نمایش داده می‌شود.
- دکمه‌های «فعال‌کردن یادآوری‌ها» و «شاید بعداً»؛ بدون درخواست مجوز خودکار. اگر اعلان فعال باشد پیشنهاد دوباره ظاهر نمی‌شود.
- اعلان روزانه شامل یک واژه فنلاندی و معنی فارسی است (۲۱ واژه چرخشی از واژگان اپ).
- GitHub Actions برای ارسال از secret موجود `ONESIGNAL_REST_API_KEY` استفاده می‌کند؛ OneSignal App ID عمومی در workflow قرار دارد. کلید محرمانه هرگز داخل سایت قرار نگیرد.
- زمان برنامه‌ریزی‌شده ۲۰:۰۰ به وقت فنلاند است؛ زمان دقیق ارسال به زمان اجرای GitHub Actions بستگی دارد.
- یادآوری‌ها فقط در صورت انتشار فایل‌های workflow، فعال بودن GitHub Actions و موفق بودن اشتراک OneSignal واقعاً ارسال می‌شوند.
